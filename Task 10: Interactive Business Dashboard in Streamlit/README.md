Task 10: Interactive Business Dashboard in Streamlit

Objective: To build an interactive business dashboard using Streamlit to analyze sales and profit data from the Global Superstore dataset.

Dataset: Global Superstore Dataset

Steps:

1. Imported required libraries.
2. Loaded dataset using Pandas.
3. Cleaned and formatted date column.
4. Created sidebar filters using Streamlit.
5. Applied filters dynamically to dataset.
6. Calculated KPI metrics.
7. Created bar charts using Matplotlib.
8. Displayed results in Streamlit dashboard.

How to Run the Project:

1. Open Anaconda Prompt or Terminal.
2. Activate environment: conda activate ml_env
3. Navigate to project folder: cd path_to_project
4. Run the app: streamlit run app.py

Output: An interactive dashboard that allows users to filter sales data and view business insights visually.

Conclusion: The dashboard provides an easy and interactive way to analyze business performance, identify top customers, and understand sales distribution across categories.
