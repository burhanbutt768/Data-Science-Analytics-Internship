
Task 3: Customer Churn Prediction

Task Objective: The objective of this task is to predict whether a customer is likely to leave (churn) or stay with the company

Dataset: Customer Churn Dataset

Source: Kaggle

Description: The dataset contains customer information such as demographics, account details, and service usage. The target variable indicates whether the customer has churned or not.

Approach: The following steps were performed to complete this task:

1. Loaded the dataset using Pandas.

2. Explored the dataset to understand structure, data types, and missing values.

3. Removed unnecessary columns like customer ID.

4. Encoded categorical variables using One-Hot Encoding.

5. Scaled numerical features for better model performance.

6. Split the dataset into training and testing sets.

7. Trained a Random Forest Classifier to predict customer churn.

8. Evaluated the model using accuracy score and classification report.

9. Analyzed feature importance to understand key factors affecting churn.

10. Visualized the top important features using a bar chart.


Results and Insights: 

1. The model successfully predicted customer churn with good accuracy.

2. Feature importance analysis helped identify key reasons why customers leave.

3. Factors like contract type, tenure, and monthly charges played a major role in churn.

4. The task provided strong understanding of classification, feature encoding, and model interpretation.

This task improved practical skills in data preprocessing, machine learning modeling, and extracting business insights from data.
