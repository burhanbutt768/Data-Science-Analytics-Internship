Task 1: Exploring and Visualizing the Dataset

Objective: To explore, summarize, and visualize the Iris dataset using Python.

Dataset: Iris flower dataset

Libraries: Pandas, Matplotlib, Seaborn

Tool: Jupyter Notebook

Approach: To complete this task, the following steps were followed:
1. Loaded the Iris dataset from a CSV file using Pandas.
2. Inspected the dataset structure by checking its shape, column names, and records.
3. Created visualizations using Matplotlib and Seaborn, including:
   - Scatter plots to analyze relationships between variables
   - Histograms to observe data distributions
   - Box plots to identify outliers and compare features across species

Results and Insights
- The dataset contains measurements of sepal and petal dimensions for three different Iris species.
- Scatter plots revealed clear separation between species based on petal measurements.
- Histograms showed that most features follow a roughly normal distribution.
- Box plots helped identify differences in petal width and length across species, with some visible outliers.

This task provided a strong foundation in data analysis and data visualization techniques using Python.
