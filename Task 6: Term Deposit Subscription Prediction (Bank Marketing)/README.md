Task 6: Term Deposit Subscription Prediction (Bank Marketing)

Objective: To predict whether a customer will subscribe to a term deposit based on demographic and campaign-related features using supervised machine learning.

Dataset: Bank Marketing Dataset

Target Variable: deposit (Yes / No)

Approach

1. Data cleaning and preprocessing
2. Encoding categorical variables
3. Exploratory Data Analysis (EDA)
4. Train-test split
5. Model training using: Logistic Regression, Random Forest
6. Model evaluation using f1-score, confusion matrix, and roc curve
7. Used SHAP to explain 5 model predictions

Results & Insights

1. Random Forest performed better than Logistic Regression
2. Previous campaign outcome and balance were strong predictors
3. Customers contacted multiple times showed higher subscription chances
