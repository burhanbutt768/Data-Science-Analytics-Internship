Task 7: Customer Segmentation Using Unsupervised Learning

Objective: To segment customers into meaningful groups based on spending behavior using unsupervised learning techniques.

Dataset: Mall Customers Dataset

Target: No target variable (unsupervised learning)

Approach:

1. Data preprocessing and scaling
2. Elbow Method to find optimal clusters
3. K-Means clustering
4. Cluster visualization using PCA
5. Interpretation of each customer segment
6. Suggest market strategies for each identified segment

Results & Insights:

1. Optimal number of clusters identified using Elbow Method
2. Clear separation between high-value and low-value customers
3. Each cluster represents a distinct customer behavior pattern

Business Value:

1. Helps businesses design personalized marketing strategies
2. Identifies premium and discount-sensitive customers
