Task 8: Energy Consumption Time Series Forecasting

Objective: To forecast household energy consumption using time series forecasting models.

Dataset: Household Power Consumption Dataset

Target Variable: Energy usage over time

Approach:

1. Data cleaning and datetime processing
2. Time series resampling
3. Train-test split (time-based)
4. Model implementation: ARIMA, Prophet, XGBoost
5. Model comparison and visualization

Results & Insights:
1. ARIMA captured short-term trends well
2. Prophet handled seasonality effectively
3. XGBoost provided strong performance after feature engineering
4. Combining statistical and ML models improves forecasting reliability
