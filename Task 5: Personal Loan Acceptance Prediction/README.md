Task 5 – Personal Loan Acceptance Prediction (Decision Tree)

Objective: To predict whether a customer will accept a personal loan offer using banking and demographic data.

Dataset: Bank marketing dataset containing customer information such as age, job, marital status, balance, and previous campaign outcomes.  
Target variable: 'deposit'

Approach
- Loaded and explored the dataset
- Performed exploratory data analysis (EDA)
- Encoded categorical variables using one-hot encoding
- Split data into training and testing sets
- Trained a Decision Tree Classifier
- Evaluated model performance using accuracy, confusion matrix, and classification report

Results & Insights
- Decision Tree provided clear and interpretable results
- Job type, balance, and previous campaign outcomes strongly influence loan acceptance
- The model effectively identified customer segments likely to accept loan offers
