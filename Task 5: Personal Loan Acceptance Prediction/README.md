Task 4 – Insurance Claim Amount Prediction

Objective: To predict medical insurance claim amounts using customer demographic and health-related data.

Dataset: Medical Cost Personal dataset includes information such as age, BMI, smoking status, region, and insurance charges.

Approach

- Loaded and explored the dataset
- Encoded categorical variables using one-hot encoding
- Split data into training and testing sets
- Trained a Linear Regression model
- Evaluated the model using MAE and RMSE
- Visualized key relationships between features and charges

Results & Insights
- Smoking status has the highest impact on insurance charges
- Higher BMI and older age are associated with increased costs
- The model provided reasonable predictions for unseen data
